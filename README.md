## 📊 核心分析流程

### 1. 数据清洗（SQL + Python）
- 将400份问卷原始数据导入阿里云RDS，用DataGrip进行探查。
- 在Python中完成缺失值处理、中文选项→数值映射，构建核心指标（情感补偿、身份认同等）。

### 2. 描述性统计与可视化
- **样本画像**：19-26岁占75%，女性占85%，在校生72%，月收入5000以下占87.8%。
- **消费行为**：月消费101-500元占**75.5%**，冲动购买倾向强占**60%**，社群高活跃占**60%**。
- **决策因素**：独特设计（3.97分）> 面料质感（3.87）> 限量/绝版（3.70）> 价格（3.25）> 设计师名气（3.15）。
- **社群参与**：60%用户每周至少参与一次社群互动。

## 3. 核心Python分析结论

### 结论A：轻量化消费 —— 低金额、高频次、强冲动
- 75.5%的用户月消费在101-500元之间。
- 60%的用户因“一见钟情”冲动购买。
- 47%的用户决策时间小于1小时。
> **商业含义**：娃衣是典型的情绪型消费品，营销应强调“即时满足”和“惊喜感”。

### 结论B：审美驱动 —— 独特设计是第一决策因素
- 决策因素中“独特设计”得分3.97/5，远高于“价格合理”（3.25/5）。
- “限量/绝版”得分3.70，显示稀缺性同样重要。
> **商业含义**：产品开发应聚焦设计创新与限量款，而非低价竞争。

### 结论C：社群放大器 —— 社群促进消费，但不是唯一渠道
- 社群参与度与消费金额呈弱正相关（r=0.07）。
> **商业含义**：社群是重要放大器，但需结合视频平台（抖音/B站）等多元渠道触达用户。

### 结论D：动机差异化 —— 情感补偿与身份认同作用复杂，需细分群体
- 情感补偿、身份认同与消费金额的相关系数均低于0.1，无直接线性关系。
- K-Means聚类将用户分为四类（浅尝辄止型、高消费中情感型、情感驱动型、深度社群型），各群体动机与行为差异显著。
> **商业含义**：通用营销无效，需针对不同群体制定差异化沟通策略（如情感驱动型强调陪伴，深度社群型强化归属感）。

### 4. 差异检验（人口统计特征）
- **年龄**：显著影响消费金额（ANOVA p<0.001），27-30 岁平均消费得分最高，15-18 岁最低。
- **收入**：显著影响消费金额（ANOVA p<0.001），不同收入群体消费行为存在明显差异。
- **性别**：无显著差异（p=0.7633），审美需求跨越性别界限，消费趋向平等化。
- **城市级别**：无显著差异（p=0.6702），体现娃圈 “线上平等” 特点，地域不影响消费。

### 5. 用户分群画像（K-Means 聚类）  

- **5.1 聚类方法与变量选择**
  
使用`消费金额 + 情感补偿 + 身份认同 + 社群参与度`进行聚类，得到4类用户：
对所有变量进行 Z-Score 标准化，消除量纲影响，保证聚类结果的稳定性。
- **5.2 最佳聚类数（K 值）确定**
   
通过肘部法则 + 轮廓系数双验证方法确定最优 K 值：
肘部法则：误差平方和（SSE）的下降拐点出现在 K=4，聚类收益趋于稳定。
轮廓系数：K=4 时轮廓系数达到峰值 0.2178，聚类内聚性与分离度最优。
最终确定K=4，既符合统计最优解，也与原论文的用户分类理论匹配。

- **5.4 用户行为特征补充验证**
  
进一步对比四类用户的消费行为特征：
全群体共性：审美偏好得分均接近 4 分，独特设计是所有用户的核心购买门槛。
群体差异：社群参与度是区分用户的最关键特征，从「浅尝辄止型」的低社群参与，到「深度社群型」的高社群活跃，分层清晰。
冲动购买：四类用户的冲动购买得分高度接近，说明冲动消费是娃衣圈的普适行为，不受用户类型影响。

### 6. 决策树（购买意愿预测）
- **模型设计**：采用 3 层深度可解释决策树，以月消费≥501 元为高购买意愿标签，核心特征为月可支配收入、城市级别、独特设计认同、视频平台使用，7:3 分层抽样划分数据集。
- **核心发现**：1.月可支配收入是绝对核心驱动（重要性 0.6934），城市级别、独特设计认同为次要因素，视频平台使用在本样本中无显著影响。
               2.整体准确率 75%，对低意愿用户识别能力极强（召回率 95%），受样本不平衡影响，高意愿用户识别能力为后续优化方向。
               3.高潜力群体特征清晰：中高收入 + 一线 / 新一线城市，高意愿概率最高达 57.9%。
- **业务启示**：营销资源聚焦中高收入一线用户，持续强化产品差异化设计，优化渠道投放策略。

### 7. AI大模型情感分析
- **数据**：210条社交媒体评论（小红书、微博）。

  - 高频情绪词：“治愈”“解压”“惊喜”。
- **交叉验证**：AI分析结论与问卷定量分析高度一致，互相验证了“情绪价值主导”的核心发现。
