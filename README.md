# Z世代娃衣消费行为分析：一场关于“情感”与“身份”的消费洞察

## 📌 项目背景
在情绪经济兴起的背景下，我们以400份问卷、15场访谈和200+社交媒体评论为数据基础，深入分析了Z世代娃衣消费者的行为动因、心理机制与市场细分。

## 🎯 项目目标
1.  **用户画像：** 描绘娃衣消费主力军的人口与行为特征。
2.  **动因挖掘：** 量化“情感补偿”与“身份认同”对购买行为的影响。
3.  **智能分群：** 利用无监督学习识别不同类型的消费者。
4.  **AI增强：** 使用大模型分析用户评论，与定量结论交叉验证。

## 🛠️ 技术栈
*   **数据清洗与探查：** SQL, Python (Pandas, NumPy)
*   **数据分析与建模：** Python (Scikit-learn, SciPy), 包括K-Means聚类、决策树、统计检验
*   **大模型应用：** DeepSeek API (情感分析、主题提取)
*   **可视化：** Tableau, Matplotlib, Seaborn

## 📊 核心分析结论
1.  **消费画像：** 用户主要为在校女大学生（占72%），消费呈“高频次、低金额、强冲动”特征。
2.  **关键驱动：** **“独特设计”**（审美）是决策的首要因素，得分远超“价格”。
3.  **用户分群：** 通过K-Means聚类，我们将用户划分为四类，其中“情感驱动型”（占34.2%）和“深度社群型”（占22.8%）是市场的核心力量。
4.  **AI验证：** 对200+评论的大模型分析显示，“治愈/陪伴”等情感类主题占比41%，与问卷分析的“情感补偿”维度高度吻合，**交叉验证了结论的可靠性**。
